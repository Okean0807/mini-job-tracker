# MiniJob Companion

Create a German-language Progressive Web App called MiniJob Tracker. Features: calendar with any work days, start/end time entry, editable hourly rates per shift, automatic calculation of hours and earnings, monthly and yearly statistics, charts for hours and earnings, Excel export (XLSX), PDF export, local storage plus cloud backup/sync, responsive mobile-first design, dark mode, German UI. Include dashboard with total hours, total earnings, average hourly rate. Use modern clean design suitable for Android phones. Build a complete working MVP.
